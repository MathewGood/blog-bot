# blogbot Chrome 확장

로그인된 브라우저 세션(NYT 구독 등)을 그대로 활용해, **현재 보고 있는 웹페이지를 한 번 클릭으로 한글 블로그 글로 변환**합니다.

## 설치 방법

1. Chrome 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **"개발자 모드"** 토글을 켠다
3. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
4. 이 폴더(`/Users/blue/Blog/chrome-extension`)를 선택
5. 툴바에 🌿 blogbot 아이콘이 뜬다. 자주 쓸 것 같으면 핀 고정.

## 사용법

1. 먼저 터미널에서 blogbot 서버 실행:
   ```bash
   cd /Users/blue/Blog && source .venv/bin/activate
   python -m blogbot web
   ```
   (또는 Finder에서 `blogbot.command` 더블클릭)

2. Chrome에서 원하는 기사를 연다 (NYT는 물론 어떤 웹페이지든).

3. 툴바의 🌿 blogbot 아이콘 클릭.

4. 팝업에서 카테고리·모델·추가 요청을 고르고 **"이 페이지로 블로그 글 만들기"** 클릭.

5. 확장이 페이지 본문을 추출 → blogbot 서버로 전송 → 글 생성.
   완료되면 팝업에 **"미리보기 열기"** 링크가 뜬다.

6. blogbot 대시보드(<http://127.0.0.1:8765>)의 "③ 초안 · 발행" 탭에서
   네이버 발행 진행.

## 어떻게 NYT 페이월을 우회하는가

확장이 페이지를 **당신의 브라우저 안에서** 읽기 때문에, NYT 로그인 세션·구독
상태가 그대로 유지됩니다. blogbot 서버가 직접 NYT를 fetch하면 403이지만,
확장은 이미 렌더링된 DOM에서 텍스트를 뽑아서 서버로 보내주니 문제 없습니다.

## 프라이버시

- 확장은 오직 사용자가 **팝업의 버튼을 눌렀을 때만** 활성 탭의 본문을 읽습니다.
- 데이터는 로컬(127.0.0.1:8765)로만 전송됩니다. 외부 서버로 나가지 않습니다.
- Anthropic API 호출은 blogbot 서버에서 수행 (사용자 API 키 사용).
