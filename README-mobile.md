# blogbot을 스마트폰·태블릿에서 쓰기

blogbot은 원래 Mac에서 도는 로컬 서버지만, 폰에서도 접속해서
글감 확인·초안 검수·발행 트리거를 할 수 있게 만들었습니다.

## 접속 범위별 선택

| 상황 | 방법 | 준비 |
|---|---|---|
| **같은 Wi-Fi 안** (집·사무실) | `--lan` 옵션으로 바인딩 → 폰이 Mac의 LAN IP로 접속 | 없음 (즉시 사용) |
| **어디서든** (LTE·해외·다른 Wi-Fi) | **Tailscale** VPN 메쉬 사용 | Mac·폰 각각 앱 설치 (10분) |

`--lan`은 이미 `blogbot.command`와 자동 시작 설정에 기본 반영돼 있습니다.
Tailscale이 함께 설치돼 있으면 서버가 자동 감지해 대시보드에 접속 URL도 함께 표시합니다.

## Tailscale 설치 (어디서든 접속)

### 왜 Tailscale인가

- **본인 기기만 접속** — 로그인한 내 계정의 기기끼리만 서로 보임 (공개 노출 없음)
- **P2P 직접 연결** — Tailscale 서버는 연결만 매개, 데이터는 통과 안 함
- **공인 IP·포트 포워딩·DDNS 불필요** — 공유기 설정 안 건드림
- **Wi-Fi 바뀌어도 주소 그대로** — 카페·해외 호텔·LTE에서도 같은 URL
- **개인 무료** — 100대까지

### 설치 순서

1. **자동 설치 도우미 실행 (권장)**
   ```
   /Users/blue/Blog/installers/setup-tailscale.command
   ```
   Finder에서 위 파일을 더블클릭하면 Homebrew로 Tailscale을 자동 설치하고
   다음 단계 안내를 띄웁니다.

2. **Mac에서 로그인**
   - 메뉴 바 오른쪽 Tailscale 아이콘 클릭 → Sign in
   - Google/Apple/Microsoft 등으로 로그인 (첫 사용자는 계정 자동 생성)

3. **iPhone에 앱 설치**
   - App Store에서 **"Tailscale"** 검색 → 설치 → 열기
   - Mac에서 쓴 **같은 계정**으로 로그인
   - VPN 프로필 허용 (Face ID/암호로 확인)

4. **blogbot 재시작**
   - `Blogbot.app` 다시 실행 (또는 터미널에서 재실행)
   - 대시보드 상단에 🌍 Tailscale 주소가 함께 표시됨

5. **폰에서 접속**
   - Mac의 대시보드에서 Tailscale URL 복사
   - 폰 Safari에서 붙여넣기
   - 공유 버튼 → **홈 화면에 추가** → blogbot 아이콘 완성
   - 앞으로 홈 화면 아이콘 탭 한 번으로 어디서든 접속

### 접속 확인

Mac이 켜져 있는 한 폰은 어디서든 이 주소로 접속 가능합니다:
- LTE/5G 셀룰러 네트워크 ✓
- 카페·공항 Wi-Fi ✓
- 해외 호텔 Wi-Fi ✓
- 다른 사람 집 Wi-Fi ✓

**Mac이 꺼져 있으면** 접속 불가능. 잠자기(sleep) 상태여도 사용에 따라 응답이 느릴 수 있으므로,
자주 쓰신다면 시스템 설정 → 잠자기 방지 켜두시길 권합니다.

## 폰에서의 사용법

### PWA 설치 (한 번만)

- Safari로 대시보드 접속
- 하단 공유 버튼(⬆️ 상자에서 화살표) → **홈 화면에 추가** → 추가
- 홈 화면에 🌿 아이콘 생성 — 앞으로 앱처럼 실행

### NYT 기사 → 블로그 글 만들기

폰에는 Chrome 확장이 없어서 원터치 자동 작성은 안 됩니다. 대신:

1. Safari로 NYT 기사 열기
2. 주소창 왼쪽 **"AA"** 버튼 → **리더 표시** (또는 리더 뷰)
3. 본문 전체를 한 번에 선택 → 복사
4. blogbot 홈 화면 아이콘 탭 → **② 새 글 쓰기**
5. 붙여넣기 → 카테고리·모델 선택 → **블로그 글 생성**
6. 완료되면 미리보기가 새 탭에서 열림

### 네이버 발행

폰에서 **③ 초안·발행** 탭의 "네이버에 올리기" 버튼을 누르면
Mac이 백그라운드에서 크로미움을 열어 스마트에디터에 자동 입력합니다.
**최종 발행 클릭은 Mac 쪽에서** 확인 후 눌러주세요 (또는 `--auto` 모드).

폰에서 트리거만 하고 나중에 Mac 앞에서 발행을 확인하는 흐름이 자연스럽습니다.

## 문제 해결

**폰에서 "이 사이트에 연결할 수 없습니다" 오류**
- Mac이 켜져 있고 blogbot 서버가 실행 중인지 확인
- Tailscale 앱이 두 기기 모두 "Connected" 상태인지 확인
- Mac에서 `Blogbot.app` 재실행 (또는 `blogbot.command`)

**대시보드 상단에 Tailscale URL이 안 뜸**
- Mac 메뉴 바의 Tailscale 아이콘 클릭 → 로그인 상태인지 확인
- 로그인돼 있다면 blogbot 서버를 재시작
- CLI로 직접 확인: `/Applications/Tailscale.app/Contents/MacOS/Tailscale ip -4`

**PWA 홈 화면 아이콘이 안 뜸**
- Safari에서 접속 (Chrome·Firefox 폰 앱은 홈 화면 추가 UX가 없음)
- 접속 후 URL 표시줄이 안 보이면 화면 위쪽 살짝 스와이프
